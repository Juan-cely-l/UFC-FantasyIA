# UFC-FantasyIA
Plataforma de fantasy league para UFC construida con Spring Boot y PostgreSQL. Los usuarios arman equipos de 5 peleadores respetando un presupuesto tipo “salary cap”, y acumulan puntos según el desempeño real de esos peleadores en eventos oficiales.

El proyecto está pensado como caso de estudio de integración entre backend tradicional robusto (modelado de dominio, transacciones, seguridad JWT, testing) y desarrollo agéntico (un asistente de IA que consume la propia API vía tool-calling, con RAG sobre estadísticas de peleadores).

Estado actual: en construcción — sigue el progreso en los commits.
